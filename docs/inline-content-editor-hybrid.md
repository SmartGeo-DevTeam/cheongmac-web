# 인라인 편집: inline / admin / hybrid

공개 화면의 편집 가능 영역은 세 가지 방식으로 운영합니다.

- **inline**: 단순 문구·버튼명·안내문처럼 자주 바뀌는 내용은 Dialog에서 즉시 DB 저장
- **admin**: 관계형 DB, 목록 추가/삭제, 정렬, 여러 의료진 연결 등은 톱니 클릭 시 해당 관리자 화면으로 바로 이동
- **hybrid**: 화면의 단순 문구는 Dialog에서 수정하고, 같은 Dialog에 `관리자에서 상세 수정` 링크를 함께 제공

`EditableRegion`은 `fields`와 `adminHref` 조합으로 위 세 모드를 자동 결정합니다.

## 의료진 상세 페이지 적용

- 프로필 이미지 → 의료진 관리자
- 이름·직책·진료과·예약 URL → 의료진 관리자 / 예약 버튼 문구는 인라인
- 전문진료분야 → 영역 제목은 인라인 / 실제 진료분야 데이터는 관계형 관리자
- 학력·약력 → 영역 제목은 인라인 / 실제 항목은 의료진 관리자
- 진료시간표 → 안내문은 인라인 / 시간표 데이터는 관계형 관리자
- 환자 후기 → 섹션 제목·더보기 문구는 인라인 / 후기 데이터는 관리자
- 미디어 → 섹션 제목·더보기 문구는 인라인 / 미디어 데이터는 관리자
- 의학 상담 → 섹션 제목·더보기 문구는 인라인 / 상담 데이터는 관리자
- 연구·발표 → 소개 문구·버튼명은 인라인 / 발표 데이터는 관리자

청맥병원처럼 한 글자 단위 문구 수정이 잦은 영역은 최대한 공개 화면에서 바로 바꾸되,
관계형 데이터의 추가·삭제·연결처럼 구조를 깨뜨릴 수 있는 작업은 기존 관리자 UI를 재사용합니다.
